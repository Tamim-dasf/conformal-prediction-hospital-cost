# Conformal Prediction for Hospital Total Cost

## Overview

This project investigates hospital total cost prediction using machine learning and conformal prediction techniques. Using the SUPPORT2 dataset, we explore patient characteristics, develop predictive models, and evaluate the uncertainty associated with cost predictions.

The main objective is to go beyond point predictions by constructing reliable prediction intervals that quantify uncertainty.

## Objectives

- Explore and analyze hospital cost data.
- Identify relationships between patient characteristics and hospital costs.
- Develop predictive models for hospital total cost.
- Apply conformal prediction to quantify uncertainty.
- Evaluate prediction interval coverage and width.

## Methodology

### 1. Data Exploration
Exploratory data analysis, descriptive statistics, and visualization of patient characteristics and hospital costs.

### 2. Data Preprocessing
Data cleaning, handling missing values, and preparing variables for modeling.

### 3. Predictive Modeling
Implementation and comparison of regression models for hospital cost prediction.

### 4. Conformal Prediction
Application of Split Conformal Prediction and CV+ to construct prediction intervals.

### 5. Model Evaluation
Evaluation of predictive performance, coverage, and prediction interval width.

## Dataset

The project uses the SUPPORT2 dataset, containing demographic, clinical, and health-related information about hospitalized patients.
